# Concept assets

This folder used to hold the "Tee to Tap" design concept. That concept is now built into the real site in [`site/`](../../site/). Open these finished files instead:

- `site/dist/bogey-club-homepage.html`: the finished page for the website
- `site/dist/bogey-club-homepage-standalone.html`: the same page with fonts and images built in, for reviewing on any device

What remains here:

| Path | Purpose |
|---|---|
| `assets/` | Logo and concept renders. `site/build.sh` uses them; the renders are for the preview only and are never uploaded. |
| `render/` | The generator for those concept renders |
